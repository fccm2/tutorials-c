Printing a Structure

file exp12.c:

#include <stdio.h>

struct _stc {
  int d1;
  float f2;
  char *s;
};

int
main()
{
  struct _stc stc = { 11, 3.4, "hello" };

  printf("st-stc: {\n");
  printf(" %d\n", stc.d1);
  printf(" %g\n", stc.f2);
  printf(" %s\n", stc.s);
  printf("}\n");

  return 0;
}

we compile test and run:

$ gcc -o exp12.exe exp12.c
$ ./exp12.exe
st-stc: {
 11
 3.4
 hello
}

here we print without a pointer to the structure, so the fields are access'd with a dot ..
