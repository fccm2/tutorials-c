Printing with printf(), from a For loop

file exp11.c:

#include <stdio.h>

int main()
{
  int d;

  d = 2;
  d++;

  printf("d-int: %d\n", d);

  return 0;
}

we compile test and run:

$ gcc -o exp11.exe exp11.c
$ ./exp11.exe
d-int: 3

you can try to put several d++;, to see the difference,
