Formating a string with snprintf()

file exp10.c:

#include <stdio.h>

int
main()
{
  size_t size;
  char str[40];
  int n;
  size = 40;
  n = snprintf(str, size, "(%d %d)", 3, 4);
  printf("# %d:%s\n", n, str);
  return 0;
}

we compile test and run:

$ gcc -o exp10.exe exp10.c
$ ./exp10.exe
# 5:(3 4)

str is a char array
